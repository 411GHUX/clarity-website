# Clarity Marketing Site

Static marketing site for [Clarity](https://getclarity.app) — a decision-making
app built around a Ready-State Check and mostly-tap flow.

## Structure

- `index.html` — page markup
- `style.css` — Terra design tokens, glass system, responsive layout
- `script.js` — modal handling, contact form (placeholder — no backend yet), toast

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static
server (e.g. `npx serve`).

## Deployment

Deployed via Vercel, connected to this repo for auto-deploy on push to `main`.
Domain: getclarity.app (DNS managed at Hover).
